# OmniOps Prisma Schema

This directory will contain Prisma schema files for the OmniOps platform.

Models will include:
- Tenant, Site, User, Role, Permission (RBAC)
- Menu, MenuItem, MenuItemModifier
- Order, OrderItem, OrderStatus
- Staff, Schedule, Shift
- MaintenanceTicket, QualityAudit
- DigitalSignage, CustomerSurvey

Schema will be added in the next task.
